## 🎬 Movie Recommendation Engine

A content-based recommendation system that generates personalized movie suggestions by analyzing a user’s “comfort movies,” search behavior, and key metadata. The model compares themes, genres, and semantic patterns to return highly relevant and tailored recommendations.
